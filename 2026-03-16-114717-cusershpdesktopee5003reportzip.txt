  2.2 Task Model

  - 3 类应用：
  | 应用              | 生成速率 | 使用比例 | 最大延迟 | 数据量  | 计算量    |

  FINISHED

  2.3 Communication Model

  - 无线信道模型
    - WLAN 带宽：5000 Mbps，PRB 总量：5000 块
    - 带宽公式：$BW = \frac{BW_{WLAN}}{PRB_{total}} \times blocks \times
  \min(1.0, (d_0 / \max(d, d_0))^\alpha)$
    - 参数：$d_0 = 20$m（参考距离），$\alpha = 0.5$（路径损耗指数）
  - PRB 分配机制
    - RL 固定分配：从全局池预留块数，上传完成后释放
    - 非 RL 动态分配：BFS 构建冲突组件 + 按 $(1.0 + \text{lanPriorityBin})$
  权重公平分配
  - 云链路：等效距离 160m 的固定距离模型

  2.4 Computation Model

  - VM 资源分配：SPACE_SHARED 策略
  - 执行时间：$T_{exec} = taskLength / vmMips$

  2.5 Energy Model

  - 传输能耗：$E_{tx} = E_{elec} \times bits + E_{amp} \times bits \times d^n$
    - $E_{elec} = 5 \times 10^{-8}$ J/bit
    - 自由空间：$E_{amp} = 10^{-11}$ J/bit/m²
    - 多径衰落：$E_{amp} = 1.3 \times 10^{-15}$ J/bit/m⁴
  - 能耗归一化：基于滑动窗口 P95（窗口大小 200 样本）

  2.6 Problem Formulation

  - 优化目标：最小化加权组合代价
  - 约束：延迟不超限、设备存活、通信范围内、PRB 池不溢出
  - 建模为 Dec-POMDP：
    - 智能体集合 $\mathcal{N}$：所有 generateTasks=true 的设备（按 DataCenter ID

  Section 4: Methodology

  4.1 MAPPO Framework Overview

  - Centralized Training with Decentralized Execution (CTDE)
    - 训练时：centralized critic 接收 global state（27D）
    - 执行时：每个 agent 仅依赖自身观测做决策
  - 整体框架图

  4.2 Observation and State Design

  - Agent Observation（13 维）：设备自身状态（CPU
  利用率、任务队列、电池、位置等）
  - Destination Features（每目的地 11 维）：类型、距离、CPU、队列、可用性等
    - 目的地顺序：local(0) → edge（按 dcId 排序）→ cloud（按 dcId 排序）
  - Destination Mask：基于 offloadingIsPossible() 的可行性掩码
  - Global State（27 维）：各层平均负载、PRB 使用率、任务成功率等
  - 公式化定义各维度

  4.3 Action Space Design

  - 双头动作空间
    - Destination Head：masked softmax → categorical 分布
    - PRB Head：8 档离散选择
        - 比例映射：{0.02, 0.05, 0.10, 0.20, 0.40, 0.60, 0.80, 1.00}
      - 实际块数：$\max(1, maxPerTask \times ratio)$，maxPerTask = 50
    - 本地执行时 PRB 强制为 0
  - Destination Fallback 机制：不可用时 fallback 到预估完成时间最短的目的地

  4.4 Network Architecture

  4.4.1 TurnActor（MAPPO Actor）

  - Agent Embedding：16D 可学习嵌入，按智能体 ID 索引
    - resize_agent_embedding() 动态适配不同智能体数量
  - Agent Encoder：agent_obs(13D) ⊕ embedding(16D) → 2 层 MLP + Tanh
  - Destination Encoder：dest_features(11D) → 2 层 MLP + Tanh
  - Destination Head：agent_encoding 与各 dest_encoding 点积 → masked softmax →
  categorical
  - PRB Head：agent_encoding → linear → 8-way softmax → categorical
  - 本地目的地（action=0）时 PRB log_prob 和 entropy 自动置零
  - 网络结构图

  4.4.2 CentralCritic

  - 输入：global_state（27D）
  - 结构：2 层 MLP（256 hidden）+ Tanh → 标量 value

  4.4.3 PPO Baseline Actor

  - 与 TurnActor 结构一致，但去掉 Agent Embedding
  - agent_encoder 直接接收 agent_obs

  4.5 Reward Function Design

  $$R = \begin{cases} -5.0 & \text{task failed} \ 5.0 - 2.0 \times latencyRatio
  - 0.5 \times energyNorm - 1.0 \times networkCost & \text{task succeeded}
  \end{cases}$$
  - latencyRatio：实际延迟 / 最大允许延迟
  - energyNorm：基于滑动窗口 P95 归一化
  - networkCost：PRB 使用比例
  - 设计动机分析

  4.6 Training Algorithm

  - PPO Clipped Objective 公式
  - 优势估计：$\hat{A}_t = R_t - V(s_t)$（每步独立任务决策，无跨步时序折扣）
  - Entropy 退火：0.02 → 0.002 线性衰减
  - 超参数表：40 episodes, γ=0.99, clip ε=0.1, LR=3e-4, 4 PPO epochs,
  minibatch=1024
  - 训练流程伪代码
