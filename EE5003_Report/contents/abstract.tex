\begin{abstract}

Task offloading in 6G edge--cloud systems requires coordinated decisions over heterogeneous computing resources and wireless bandwidth under mobility, fluctuating load, and link contention. In a three-tier LOCAL--EDGE--CLOUD architecture, the joint optimization of offloading destinations and Physical Resource Block (PRB) allocation forms a high-dimensional combinatorial problem for which static heuristics are difficult to adapt across dynamic conditions.

To address this challenge, this report presents an on-policy multi-agent reinforcement learning framework based on Multi-Agent Proximal Policy Optimization (MAPPO). The system is formulated as a decentralized partially observable Markov decision process, where each task-generating device acts as an agent. The framework adopts centralized training with decentralized execution: each agent selects both an offloading destination and a PRB allocation level from a dual-head discrete action space using local observations, while a centralized critic evaluates the global system state during training. A customized PureEdgeSim-based Java--Python co-simulation environment is developed to model large-scale edge--cloud systems with mobility, heterogeneous resources, and PRB-constrained wireless contention.

The implementation integrates a Java discrete-event simulator with Python learning modules for MAPPO and a shared-policy PPO baseline. Under a standard configuration with 160 devices and a 30-minute simulation horizon, both learned policies substantially outperform heuristic schedulers. MAPPO achieves a three-seed mean task success rate of 99.9237\%, while PPO reaches 99.9436\%, both significantly exceeding the strongest heuristic baseline, ROUND\_ROBIN, at 90.3869\%. Ablation results further show that adaptive PRB allocation is the dominant contributor to performance: fixing PRB allocation reduces mean success to 92.3822\% and increases mean energy consumption to 309.2645~Wh, whereas removing agent embeddings causes only a minor degradation in reliability. Relative to PPO, MAPPO does not dominate all seed-averaged aggregate metrics, but it shows a more favorable residual deadline-failure profile in the present setting.

These results support on-policy reinforcement learning as an effective approach for joint offloading and radio-resource control in the studied simulator setting. More specifically, they indicate that adaptive PRB control is the primary source of gain, while explicit multi-agent conditioning contributes a smaller, reliability-oriented benefit.

\textbf{Keywords:} Multi-Agent Reinforcement Learning, MAPPO, PPO, Task Offloading, PRB Allocation, 6G Edge-Cloud Computing, PureEdgeSim.

\end{abstract}
