\section{Conclusion}
\label{sec:conclusion}

\subsection{Summary}
\label{subsec:conclusion-summary}

This report studied joint task offloading and PRB allocation for a three-tier 6G edge-cloud computing architecture. The problem was formulated as a Dec-POMDP and solved with an on-policy MAPPO framework operating under centralized training and decentralized execution. A customized PureEdgeSim environment was developed to support PRB-aware communication, distance-sensitive wireless attenuation, device-level observations, and Java-Python co-simulation. Experimental results show that the learned policy reaches a task success rate of \(99.9401\%\) on average across three evaluation seeds while maintaining an average total delay of \(4.5434\,\mathrm{s}\).

Beyond the raw metrics, the learned behavior is also meaningful. MAPPO does not collapse to a single execution tier or a single PRB level. Instead, it distributes tasks across local, edge, and cloud resources while favoring moderate PRB reservations for most decisions. This confirms that the policy is learning a genuine joint scheduling strategy rather than exploiting one trivial shortcut.

\subsection{Limitations}
\label{subsec:conclusion-limitations}

Several limitations should be noted. First, the study is still based on simulation, so there remains a gap between the modeled wireless environment and a real 5G or 6G deployment. Second, the current experiments use a fixed scenario scale with 160 devices and a fixed infrastructure topology. Third, the reward function is hand-designed and may not be optimal for every workload mix or operator objective. Fourth, while the training pipeline already supports GAE, the event-driven task setting still simplifies some long-horizon temporal dependencies that would become more pronounced in persistent real-world traffic traces.

Another practical limitation is that not all baseline runs are currently preserved as structured numeric exports in the workspace. The qualitative dashboard comparison is still useful, but a full all-baseline table should be regenerated from fresh evaluation runs before the final camera-ready version of the report is submitted.

\subsection{Future Work}
\label{subsec:conclusion-future}

There are several natural directions for future work.
\begin{itemize}
    \item Scale the simulator to denser deployments and larger edge clusters in order to test how MAPPO behaves under heavier multi-agent coupling.
    \item Extend the framework to dynamically varying agent populations so that task-generating devices can join or leave online.
    \item Investigate richer temporal credit assignment, including more explicit long-horizon traffic models and alternative return estimators.
    \item Integrate the scheduling framework with real wireless traces or a hardware testbed to reduce the simulation-to-reality gap.
    \item Explore automatic reward-weight tuning or multi-objective optimization so that latency, energy, and network cost trade-offs can be adapted systematically.
\end{itemize}

Overall, the results indicate that on-policy multi-agent reinforcement learning is a practical and promising approach for coordinated offloading and radio-resource control in hierarchical edge-cloud systems.
